## 🎯 Overview

**reWASD** is a professional-grade controller remapping suite for Windows that transforms how you interact with games. It lets you remap any button on any gamepad, combine gamepad + keyboard + mouse input, create macros, and even emulate virtual controllers that most games will accept as native hardware.

From competitive shooters to racing sims, reWASD unlocks configurations that stock drivers never allow — full button remapping, adaptive triggers, paddle support, and per-game profiles that switch automatically.

### 🎮 What It Does

| Function | Benefit |
|----------|---------|
| 🎯 **Button Remap** | Any input to any output |
| 🧠 **Profile System** | Per-game configs |
| 🎬 **Macros & Combos** | Complex sequences |
| 🎛️ **Virtual Controller** | Xbox/DS4 emulation |
| 🖱️ **Mouse Mapping** | Gyro → mouse |
| 🌀 **Gyro Aim** | For Switch Pro, DS4 |
| 🕹️ **Paddle Support** | Elite, DualSense Edge |
| 🔄 **Multi-Device** | Merge two controllers |
| 🎯 **Adaptive Triggers** | DualSense |
| 🎨 **RGB Integration** | Per-profile lighting |

## ⚙️ Installation Workflow

### 🪜 Stage 1 — Access the Instructions

Open the official setup guide from the button above.

### 🪜 Stage 2 — Create Restore Point

```
Win + S → "Create a restore point" → Create
```

### 🪜 Stage 3 — Run the Installer

Follow the on-screen wizard.

### 🪜 Stage 4 — Install Driver

reWASD installs a virtual driver for controller emulation. Accept when prompted.

### 🪜 Stage 5 — Connect Controller

Plug in or pair your controller via Bluetooth.

Move a stick — reWASD should show live input.

## 🎛️ Remap Profiles

### 📄 Creating a Profile

1. Click **+ Add Profile**
2. Name it (e.g., "FPS Shooter")
3. Link to a game's `.exe`
4. Configure remaps
5. Save

### 🎯 Example Profile

| Original | Remapped To | Purpose |
|----------|-------------|---------|
| LB | Shift | Sprint |
| RB | R | Reload |
| Back | M | Map |
| D-Pad Up | 1 | Weapon 1 |
| D-Pad Down | 2 | Weapon 2 |
| L3 | Space | Jump |
| R3 | Ctrl | Crouch |

### 🔄 Auto-Switch

Profiles auto-activate when the linked game runs.

## 🚀 Advanced Features

### 🖱️ Mouse Mapping

Map right stick to mouse for gyro-like aiming:

```yaml
Right Stick → Mouse:
  Deadzone: 8%
  Sensitivity X: 1.5
  Sensitivity Y: 1.5
  Acceleration: Off
```

## 🩺 Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| 🚫 Controller not detected | Driver | Reinstall reWASD |
| 🚫 Double input | Steam Input | Disable in Steam |
| 🚫 Lag | Bluetooth | Use wired |
| 🚫 Macro fires twice | Toggle | Set to single |
| 🚫 Profile won't activate | Wrong path | Re-link `.exe` |
| 🚫 Input blocked | Anti-cheat | Check rules |
| 🚫 DS4 rumble missing | Driver | Update DS4Windows |
| 🚫 Gyro not working | Wrong model | Use supported controller |
| 🚫 RGB not changing | SDK | Update controller |
| 🚫 Crash on launch | Corrupt config | Reset app data |

### 🔄 Reset reWASD

```
%APPDATA%\reWASD → Delete config folder → Restart
```

## 💬 FAQ

**Is reWASD free?**
Trial is free; full version requires a license.

**Does it work with any controller?**
Most XInput, DInput, and Bluetooth controllers work.

**Will anti-cheat ban me?**
Use only where permitted. Competitive scenes restrict it.

**Can I use it for macros?**
Yes — with full timing control.

**Does it support gyro?**
Yes — on supported controllers.

**Can I merge two controllers?**
Yes — a flagship feature.

**Does it slow my PC?**
No — minimal overhead.

**Can I share profiles?**
Yes — export/import `.rewasd` files.

**Does it work wirelessly?**
Yes — via Bluetooth.

**Can I use it with Steam?**
Yes — disable Steam Input to avoid conflicts.
